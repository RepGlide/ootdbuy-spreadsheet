Coordination Check Guide

Once the external page opens, re-check purpose, options, size context, color description, and changeable details — without turning coordination into verification.

Coordination is not verification

Checking whether pieces answer the same purpose is useful — but it does not confirm a product is authentic, well made, or true to its description. Keep the two apart.

Purpose

Does this page still serve the anchor? Re-read the title and the item it shows. If the page has drifted to a different purpose than the row you opened, note it and do not silently swap the anchor.

Options

Which option is selected? A listing shows many colors and versions. Re-read the selector: the option shown now may not be the one you meant, and a description is only meaningful against a specific option.

Size context

Which size does this refer to? A size chart or a fit note is only useful against the specific size and option. If the page shows no size context, that space stays empty.

Color description

Does the color match? A written color can differ from a photo, and both can differ from what you expect. Re-read the written description rather than trusting the image alone.

Changeable details

What keeps shifting? Material, fit, or availability can change between pages. Mark anything that shifts as still to confirm, and leave it in an empty frame until it is settled.

A worked re-check

  1. Purpose: the page shows a bag, matching the anchor.
  2. Options: a color is selected that differs from the row — noted.
  3. Size context: no size is shown — left empty.
  4. Color description: the written color does not match the photo — noted.

Editorial example — not an outfit, recommendation, product set, or saved board.
